# 🎬 Film Finder Website

## 🚀 About
Film Finder is a full-stack web application that helps users explore and track movies. The site displays upcoming releases, a catalog of existing movies, and a personalized “watched list.”

Users can:
- Search for movies via an external movie API 🎥

- Add movies they’ve watched to a personal list

- Rate movies (1–5⭐) and leave written reviews

- View upcoming movie releases and details

This project combines frontend interactivity (Vue.js) with a Go-based backend to create a smooth and responsive experience.

⚙️ Tech Stack

**Frontend:** Vue.js, JavaScript, HTML, CSS

**Backend:** Go (Golang)
API: Movie Database API (e.g., TMDB or OMDb)
Tools: Node.js, npm
